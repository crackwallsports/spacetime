# 轻量记账 Demo

这是一个只使用浏览器的 LPLF 入门 Demo。它不连接服务器，也不会自动保存数据；请使用“导出 / 备份”下载 JSON 文件，并在下次打开时用“导入 JSON”恢复。

## 打开

直接双击 `index.html` 即可使用，不需要启动服务器，也不需要安装任何依赖。页面不会访问网络；数据只存在于当前页面内，关闭页面前请导出 JSON 备份。

如果你只是想用开发者工具检查页面，也可以选择用任意静态服务器预览，但这不是应用运行所必需的。

## 记账方式

每笔交易都是“转出账户 → 金额 → 转入账户”。例如：

```text
现金 → 30.00 → 餐饮
```

金额在 JSON 中用整数分保存：`3000` 表示 `30.00`。账户余额由初始余额和全部交易计算得出。

`sample-ledger.json` 是可以直接导入的示例数据。
