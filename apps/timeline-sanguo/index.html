S0: 曹操南征前的世界状态

Snapshot
时间：208年7月 (建安十三年七月)

初始世界状态：曹操整训完毕准备南下，刘表病重，荆州继承危机爆发在即，刘备依附新野，江东孙权静观其变。

S0 → S1: 系统失稳与压力释放

Transition
时间：208年7月 - 8月

驱动力：刘表病逝，荆州权力真空；曹大军南下，防线崩溃。

⚙️ 展开演化细节与驱动力
触发驱动力 (Trigger Drivers):
  • 刘表去世 (D_Liu_Biao_Death): 荆州牧刘表病逝，引发权力继承真空 [Fact]
  • 曹操南征 (D_Cao_Cao_Advance): 曹操南征大军越过边界，长驱直入，带来极限军事压迫 [Fact]
结构性冲击 (Structural Impact):
  • 刘表死后，蔡瑁等拥立次子刘琮继位，排挤长子刘琦，荆州防御体系崩溃 [Fact]
  • 刘备客军丧失政治互信与后勤，瞬间暴露于曹操兵锋之下 [Inference]

S1: 荆州易主与大军压境

Snapshot
时间：208年8月 - 9月上旬

刘表去世后，刘琮继位。曹操大军压境，新野、襄阳危在旦夕。刘备集团因信息被封锁，处于极其被动的状态。

决策: 刘琮投降抉择

Decision
时间：208年9月

曹军大举抵达宛城，刘琮面临内部蔡氏世家大族联合劝降、以及外部军事毁灭威胁的双重绝局。

已选：举州降曹
不费一兵一卒举州降曹。实际结局：刘琮被明升暗降并软禁，蔡瑁等功臣获封侯。
未选：联刘御曹
联合樊城的刘备死战。意图结局：依托天险阻挡曹操。实际可能：荆州陷入战火或被刘备喧宾夺主。

S1 → S2: 连锁崩溃与当阳追击

Transition
时间：208年9月中旬

驱动力：刘琮正式降曹，江防瓦解；刘备仓皇撤走，曹军虎豹骑极速追杀。

⚙️ 展开演化细节与驱动力
触发驱动力 (Trigger Drivers):
  • 刘琮降曹执行 (D_Liu_Cong_Surrender_Executed): 刘琮开城归顺，导致襄阳及汉水防线不战而散 [Fact]
  • 刘备滞后知悉 (D_Liu_Bei_Late_Discovery): 刘备在樊城很晚才知刘琮已降，陷于腹背受敌的极危死局 [Fact]
结构性冲击 (Structural Impact):
  • 刘备被迫携带十万不愿降曹的百姓撤退，行军极为迟缓 [Fact]
  • 曹操唯恐刘备占领江陵获得军资，派虎豹骑一日一夜疾驰三百余里实施长坂追截 [Fact]

S2: 当阳惨败与江陵易手

Snapshot
时间：208年9月中旬 - 下旬

长坂坡之战爆发，刘备残部精锐全军覆没，仓皇退守夏口；曹操兵不血刃接收江陵大批军粮战船；江东孙权集团面对曹操顺流而下的极限威压，文臣武将陷入激烈撕裂。

S2 → S3: 舌战群儒与结盟建立

Transition
时间：208年10月

驱动力：诸葛亮亲赴江东舌战群儒；鲁肃夏口奔走外交；周瑜被紧急召回柴桑论证抗曹策略。

⚙️ 展开演化细节与驱动力
触发驱动力 (Trigger Drivers):
  • 诸葛亮柴桑游说 (D_Zhuge_Liang_Diplomacy): 特使诸葛亮舌战江东文臣，精辟分析曹操兵家之忌与两家协同作战的利益空间 [Fact]
  • 召回周瑜决策 (D_Zhou_Yu_Recall): 鲁肃极力劝阻迎曹，孙权召回鄱阳训练水军的周瑜，稳定主战信心 [Fact]
结构性冲击 (Structural Impact):
  • 孙权拔刀砍案，宣告江东全力转入战时动员，压制投降言论 [Fact]
  • 刘备在夏口、樊口获得最重要的战略喘息机会与同盟保护 [Inference]

S3: 孙刘同盟建立

Snapshot
时间：208年10月

孙刘大联盟正式缔结。孙权任命周瑜、程普为左右都督，率江东三万精锐水军西进抗曹；刘备残兵协同驻防，依托长江、汉水天险，共同构筑军事防线。

决策: 孙权生死抉择

Decision
时间：208年10月

曹操送达“会猎吴地”的逼降恐吓信，江东大震，张昭等主臣极力主和，刘备特使诸葛亮与周瑜、鲁肃对其进行最后的游说博弈。

已选：联刘决战
拔刀断案，主战迎击曹操。实际结局：赤壁用火攻大败曹军，保全江东独立并锁定三分天下。
未选：投降迎曹
顺应张昭等劝降，解除江防。意图结局：保全江东宗庙性命。实际可能：孙氏降为俘虏软禁，世家获得保全。

S3 → S4: 初战退守与连环锁船

Transition
时间：208年11月

驱动力：赤壁遭遇战曹军首战失利退乌林；曹操下令连环战船以解决水土不服与风浪颠簸。

⚙️ 展开演化细节与驱动力
触发驱动力 (Trigger Drivers):
  • 赤壁初遭遇 (D_First_Clash_Chibi): 联军与曹操水军前锋在赤壁遭遇，曹军大病不习水战，初战失利退驻乌林 [Fact]
  • 连环锁船决策 (D_Cao_Cao_Chaining_Ships): 曹操为克服北方兵晕船，下令将千艘战船首尾相连停泊 [Fact]
结构性冲击 (Structural Impact):
  • 两军进入隔江长时期对垒。连环船提供了致命的单一火攻破绽 [Inference]
  • 曹大军由于营内严重爆发的疫病，非战斗减员极其严重，战斗力空前滑坡 [Fact]

S4: 赤壁对峙与战前态势

Snapshot
时间：208年11月 - 12月

隔江对峙达到巅峰。曹操连环船成为巨大破绽，周瑜、黄盖密谋执行诈降放火之策，东南风起决战一触即发。

S4 → S5: 东南风起与赤壁大劫

Transition
时间：208年12月中旬

驱动力：反常东南风突起，黄盖率火船冲撞曹操连环战船；大火借风蔓延引爆江北连营。

⚙️ 展开演化细节与驱动力
触发驱动力 (Trigger Drivers):
  • 黄盖诈降纵火 (D_Huang_Gai_Fire_Attack): 黄盖十艘轻捷战船满载枯柴膏油诈降，接近时顺风扬帆突袭，大火冲天 [Fact]
  • 冬季东南风起 (D_Southeast_Wind_Occurrence): 气候出现反常东南风，推波助澜，火势瞬间吞噬江北曹军主力战船及陆军旱营 [Fact]
结构性冲击 (Structural Impact):
  • 曹军引以为傲的水军彻底崩溃，曹大军彻底败走北撤 [Fact]
  • 刘备、周瑜主力水陆大军乘势渡江追击，扫荡残敌 [Fact]

S5: 赤壁大捷与曹军北撤

Snapshot
时间：208年12月中旬 - 下旬

赤壁火攻告捷。曹操残军在大风、大雪、大面积疫病肆虐下败走华容道，死伤无数；曹操被迫留曹仁、徐晃守江陵，自己带残兵还邺，放弃短期统一全国的尝试。

S5 → S6: 焦土攻坚与南郡对峙

Transition
时间：208年12月 - 209年

驱动力：周瑜统领江东主力跨江围攻江陵；曹操留守守将曹仁展开焦土守城战。

⚙️ 展开演化细节与驱动力
触发驱动力 (Trigger Drivers):
  • 周瑜围攻江陵 (D_Zhou_Yu_Attack_Jiangling): 周瑜率孙吴绝对精锐，渡江发动惨烈持久的江陵夺城战 [Fact]
  • 曹仁死守焦土 (D_Cao_Ren_Rigid_Defense): 曹仁以极强战术意志守城，对江东形成极其惨重的物理消耗 [Fact]
结构性冲击 (Structural Impact):
  • 曹操、江东主力被深困南郡泥潭，造成荆州中南部大空隙 [Inference]
  • 刘备获得惊天安全时空，得以实行“避实击虚”的自主战略 [Inference]

S6: 南郡僵局与力量真空

Snapshot
时间：209年整年

江陵（南郡）处于漫长一年的攻坚消耗中。曹仁、周瑜拼死相搏；刘备在此战略真空期暗中谋划夺取毫无防守的荆州南部各郡。

S6 → S7: 避实击虚与南征四郡

Transition
时间：209年底

驱动力：刘备亲率赵云等将南征，武陵、长沙、桂阳、零陵四郡不战或倒戈，刘备军力数月内实现原子裂变式暴增。

⚙️ 展开演化细节与驱动力
触发驱动力 (Trigger Drivers):
  • 刘备游击南征 (D_Liu_Bei_Southern_Campaign): 刘备乘着周瑜、曹仁拼死相顾无暇他顾，挥师横扫防备空虚的荆南四郡 [Fact]
  • 四郡太守易帜 (D_Four_Shires_Surrender): 长沙韩玄、零陵刘度、桂阳赵范、武陵金旋投降或兵溃归宿刘备 [Fact]
结构性冲击 (Structural Impact):
  • 刘备不仅获得广袤根据地，更借收降地方军民让兵力暴增至数万人，彻底走出客军绝境 [Fact]
  • 割据力量天平迅速倾斜：周瑜伤疲拿下南郡后，发现处于做大的刘备的合围中 [Inference]

S7: 刘备暴涨与借地博弈

Snapshot
时间：209年底 - 210年

刘备坐拥四郡，但发现四郡缺乏长江防线支撑，且与后防脱节。周瑜虽夺下江陵，但江东在南郡与曹军直接冲突、后勤极度吃紧，两家陷入复杂的割据地缘角力。

决策: 租借南郡（借荆州）

Decision
时间：210年

210年周瑜病逝，留守江陵的鲁肃力劝孙权采取地缘转嫁战略。刘备亲临京口，求借南郡以连接自身底盘并作为进取西川之跳板。

已选：租借南郡
将南郡江陵交给刘备督管。意图结局：让刘备当挡箭牌挡住曹操。实际结局：刘备由此入蜀。但未来领土摩擦导致同盟破裂、吕蒙白衣渡江袭杀关羽。
未选：扣留刘备
听从周瑜生前之计，扣押刘备、吞并其军。实际可能：荆南立刻叛乱反吞，导致联盟崩溃、曹操乘机南征一举覆灭江东。

S7 → S8: 借地均势与川蜀跳板

Transition
时间：210年底

驱动力：孙权同意鲁肃之策，正式将江陵（南郡）移交刘备。刘备自此连片拥有荆北南、荆南，军事大门洞开。

⚙️ 展开演化细节与驱动力
触发驱动力 (Trigger Drivers):
  • 鲁肃鼎力主盟 (D_Lu_Su_Alliance_Strategy): 鲁肃劝说孙权借地，认为‘曹操虽退，实力仍强。将江陵借刘备，一可树抗曹大敌，二可固两家盟好’ [Fact]
  • 周瑜病逝临终 (D_Zhou_Yu_Passing): 周瑜病卒，江东主战激进派受阻，鲁肃继任，抗曹主线转为守成与战略同盟 [Fact]
结构性冲击 (Structural Impact):
  • 刘备获得汉水与长江交汇的绝佳桥头堡，入蜀通道打通 [Inference]
  • 江东大军收缩至长江下游，后撤防线，地缘格局重归稳定，等待下一次均势打破 [Inference]

S8: 三分天下与入蜀西征

Snapshot
时间：210年底 - 211年

借地博弈尘埃落定。曹操扼守襄阳，孙权盘踞沿江柴桑以东，刘备任命关羽率重兵坐镇江陵锁死大门，自己亲率几万精锐主力逆长江而上、正式开启入蜀西征。三国鼎立的终极地缘帷幕彻底拉开。
